# Source transcription comparison

The republished 2017 map guide at https://www.scribd.com/document/351529746/Revelations-Guide contains `CF85C 3D87A ABE63`. Both root and an independent agent visually inspected the original texture export, `literature_review/ori_trench_paper_2016.png`, and read `CF85C 2D87A ABE63`. The glyph matches the diagonal/base shape of nearby2s. The original ciphertext was therefore left unchanged. This mirror is not an authenticated correction to the original texture.

Difference: zero-based hex offset362 / byte181, a proposed2→3 substitution. A single value substitution would produce local damage under the tested CFB8/ECB/CBC modes after a correct permutation; it would not normally conceal every unaffected readable region. It could affect a whole-message cipher such as XXTEA, but there is no image support for replacing the2.
